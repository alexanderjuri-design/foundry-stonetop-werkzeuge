# Stonetop Werkzeuge

Kleines Foundry-VTT-Modul für Stonetop mit dem [pbta-System](https://github.com/asacolips-projects/pbta).

- **Ausrüstungs-Insert im Equipment-Reiter:** zeigt die erste Textseite eines Vorlagen-Journals (Standard: „Inventory Insert – Vorlage“) als anklickbares Insert; die Haken werden je Charakter gespeichert.
- **Kästchen und Notizfelder in Moves und Items:** `<input type="checkbox">` und `<input type="text">` in Item-Beschreibungen werden beim Anklicken ins Item zurückgeschrieben (z. B. Potential for Greatness).
- **Dauerhafte Journal-Checkboxen:** für Journale, deren Name mit einem der eingestellten Präfixe beginnt.

Installation: Manifest-URL
`https://github.com/alexanderjuri-design/foundry-stonetop-werkzeuge/releases/latest/download/module.json`

Getestet mit Foundry 14 und pbta 1.2.2.
